# Blekherman–Parrilo–Thomas

Code and computational experiments accompanying my study of *Semidefinite Optimization and Convex Algebraic Geometry* by Grigoriy Blekherman, Pablo A. Parrilo, and Rekha R. Thomas.

This repository contains selected implementations and computational solutions to exercises from the book. It is not intended to be a comprehensive collection of solutions or a general-purpose optimization library.

The code is written as needed while working through the material, primarily for learning and experimentation.

## Contents

The repository is organized by chapter. Only exercises that benefit from a computational approach are included.

## Disclaimer

These are personal study notes and independent implementations. They may contain errors and are not official solutions endorsed by the authors or publisher.

## Reference

Grigoriy Blekherman, Pablo A. Parrilo, and Rekha R. Thomas, *Semidefinite Optimization and Convex Algebraic Geometry*, SIAM.
